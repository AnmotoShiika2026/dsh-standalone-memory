# 五分钟上手：散场后找回一句台词

只用虚构内容做第一次测试，先不用私人资料。步骤展示操作和判断方法，不是预填的测试结果。

1. **进场。** 在已安装插件的 profile，选一个固定工作目录。先单独发「查询本工作区对话归档状态」。确认实际回执中的工作区与 `enabled`。若关闭是你之前的选择，就保持关闭；若确实要试归档，单独发「开启本工作区对话归档」，再确认。
2. **演一小段。** 发「排练开始。我演站长，你演旅客。我的开场白是：末班车还没走。请用一句台词接戏。」留意助手实际答了哪一句。角色、地点和行动都属于这一幕，不是用户现实经历。记录当天的本地日期。
3. **换会话，不换目录。** 在同一 profile、同一初始工作目录另开会话。分别发「回查本工作区 2026-11-25 的用户聊天记录」和「回查本工作区 2026-11-25 的助手聊天记录」，把例中日期替换成排练那天。让助手按角色列出原句；若只列摘要，再要求在当前查询中展开该条原文。**用户那句不能署成助手；助手接的台词不能署成用户。** 若结果分页，翻到下一页再判断，不拿第一页代表全部。
4. **日常约定走另一条路。** 若你真想长期保留一条信息，可以发「请记住：这个项目的插画交付用 PNG。」等真实保存回执，再到新会话要求「查一下插画交付的记忆，展开原话」。如果后来改成 SVG，请清楚说明变更，核对新旧两句，不让助手把历史值当现行值。自然问答没有匹配时，以原话和说话人为准，而不是重复诱导它猜。
5. **模型没查怎么办？** 明确发「我想找本工作区里我提到过末班车的那条消息，能不能把我的原话贴一下吗？」；或在日期已知时回到第 3 步。要求实际查询结果、来源和未查全的部分，不接受助手只在正文里写一个工具名。若仍查不到，检查 profile、初始目录、日期、角色、归档状态、宿主会话是否仍存在；只说「此范围没有查到」，不等于这句话不存在。

不想继续归档，单发「关闭本工作区对话归档」，再查状态。日后重新开启不会补录这段空窗。要清除既有资料、区分插件库和宿主日志，请看 [升级与维护](../UPGRADE-CONSENT.md)。
