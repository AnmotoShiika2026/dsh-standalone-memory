# 原话记忆

在同一 profile 和工作区找回按日期、角色区分的原话，或按主题搜索精选笔记。本地保存未加密，默认会保存符合条件的对话。请先了解开关再发送私人内容。

打开 **设置 → 原话记忆**，先在「主页」了解使用方法，在「常规设置」决定以后保存和召回什么。「导入旧对话」和「会话记忆隔离」按工作区列出宿主目录，不必先打开会话才看得到。看到名称不代表已导入或能读取原文；可操作的会话需要分别勾选并确认。搜索原话、修改笔记与清理记录在「查询及其他」。
