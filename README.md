# 原话记忆 · DSH 独立插件

**0.11.2 · 本地离线安装包。** 这个插件帮你在同一个 DSH profile、同一个工作目录里找回对话原文。它回答的是「谁在什么时候说过什么」，不保证「当时的话现在仍然成立」。例如，助手在戏里说“我在北站等你”，可以作为助手台词回看，不能记作用户住在北站。

## 让 AI 帮你安装（Windows）

复制给能运行本机命令的 AI：

> 请按 https://github.com/AnmotoShiika2026/dsh-standalone-memory/blob/main/AGENTS.md 安装原话记忆 v0.11.3 到 DSH 的 desktop profile。先说明归档默认行为，核对安装包哈希，安装后验证版本；不要导入旧聊天或自动重启。

其他 profile 请把 `desktop` 换成实际名称。已有 DSH 即可，无需克隆仓库或登录 GitHub。

## 安装之前先决定要不要留原文

新工作区默认在本机保存符合条件的用户文本和已完成的助手可见答复；原有工作区已明确关闭的状态应保留。它默认不补录安装前的聊天，也不保存推理、工具调用或未完成的输出。库是**明文**，不是保密保险箱；本地检索不需要密钥，但发送给对话模型的原文仍受你所选模型和 DSH 的数据政策约束。若不想留存，先看下文的开关，再发送私人内容。

拿到经维护者确认的 **0.11.2 本地 tgz 和独立 SHA-256** 后，在 PowerShell 执行；把 `desktop` 换成你实际使用的 profile。不要用开发包替代：

```powershell
$pkg = 'C:\Downloads\dsh-standalone-memory-0.11.2.tgz'
(Get-FileHash -Algorithm SHA256 $pkg).Hash   # 人工对照；不一致就停止
dsh --version
dsh plugin --profile desktop add --offline --ignore-scripts "$pkg"
```

退出并重开对应 DSH 实例，进入打算长期使用的工作目录。单独发送「查询本工作区对话归档状态」，要求助手报告工具的实际返回。没有工具回执时，不要假定已经安装成功或已经关闭。已有旧库请先看 [升级与维护](UPGRADE-CONSENT.md)。

## 三种读法，别把它们混用

|你想知道什么|可以怎么说|结果能证明什么|
|---|---|---|
|以前有没有说过某个词？|我想找本工作区里我提到过琥珀灯的那条消息，能不能把我的原话贴一下吗？|查有许可的用户原句；找到只证明说过。|
|某天角色到底怎么说？|回查本工作区 2026-11-25 的助手聊天记录|按写入时宿主本地日期返回获准原文；日期换成实际那天，`助手`可换成`用户`。|
|现在沿用哪项约定？|请记住：这个项目的插画交付用 PNG。下次可问「查一下这个项目的插画交付约定，给我看保存的原话」。|查精选笔记与来源。若你后来改过，旧引文仍是历史；没找到新的有效约定就先问，不替你选。|

自然追问可能不触发工具，或工具返回空；这不表示你没说过。先点明**本工作区、说话人、日期或原词**，让助手实际查并贴出来源。不要把查不到变成猜测。见 [五分钟上手](docs/QUICKSTART.md)。

## 设置 → 原话记忆

顶部有五个标签：**主页、常规设置、导入旧对话、会话记忆隔离、查询及其他**。主页介绍插件能保存什么、如何使用；改开关去「常规设置」，找原文去「查询及其他」。要一次性补录旧对话或改变记忆共享范围，请分别使用对应管理页。仅浏览目录、筛选或勾选都不会修改记录。

打开 DSH 的「设置」，在左侧选择「原话记忆」。这里显示当前 profile 已保存的宿主配置，不是某个工作区正在运行的状态。修改常规开关后选「保存更改」；显示「已保存并读回」后，**退出并重新打开此 profile 的 DSH 实例**，不只是刷新设置页。加载失败不会显示假定默认值；保存失败、读回失败或冲突时面板给出原因，选「重新读取」确认现值再决定是否重试。只读配置不能编辑。

**导入旧对话**：打开同名标签页即可浏览宿主索引里的工作区和会话，不需要先逐个打开。工作区按侧边栏名称显示，鼠标停在名称上可查看完整路径；同名工作区仍是不同的选择。展开工作区可查看会话名；在可操作的条目中，勾选一个会话、工作区或筛选结果，核对清单后确认导入。浏览目录不会导入对话，也不会开启持续补录。目录可以展示旧会话而不读取对话正文；能看到名字不等于当前配置可以处理。归属无法核实等不可操作情形以行内说明为准。「查询及其他」不会因为管理页能看到更多会话而获得更多原文。

**在控制台管理资料**：选中会话后，可在「精选记忆」浏览、搜索、读取或收录原话，也可修改摘要、关键词或删除指定笔记；「历史记录」用于按日期、角色查看归档或检索历史原话。导入的归档不自动变成偏好或取得其他检索许可。清理前请核对回执里的 ID 与所选范围；删除插件记录不删除 DSH 自身聊天。

**按会话隔离记忆**：进入「会话记忆隔离」标签页，按工作区或单个会话选择，核对后保存。这里的选择与导入页互不相干。已有的全局隔离不会因升级而解除。开启单个会话的隔离时，可核实属于它的旧共享记录转入私域；发生冲突的记录保守封存。以后取消隔离，只恢复共享读写，不会把私域原话重新公开。隔离只影响本插件，不改变 DSH 自身的聊天记录。

插件开关不覆盖工作区的关闭决定。若刚关闭插件级归档，在重启并查询实际状态前请勿发送私人内容。

## 怎么关，关的是哪一层？

- 单独发送「关闭本工作区对话归档」，再单独查询状态，确认 `enabled:false`；需要时以「开启本工作区对话归档」恢复。关闭不是删除，也不是清除宿主聊天。关闭期间不补录。插件级 `conversationArchive:false` 用于停用归档；事实收录和历史回查是另外的功能。
- `autoCapture:false` 停止自动收录；`autoRecall:false` 停止自动召回；`historyLookup:false` 停用主动历史回查及依赖该功能的查询入口。以上是插件配置项，不是要发给助手的聊天内容。若只想不再使用插件，可卸载后重启该 profile；卸载不等于删除资料。
- 若要忘记某条内容，用保存回执中的真实 ID 单独发「删除记忆 <ID>」，以工具返回 `deleted:true` 为准；未确认就视为没删。不要从相似台词猜目标。删除、隔离和关闭均不擦除系统备份、SQLite 残留或 DSH 日志。维护范围见 [升级说明](UPGRADE-CONSENT.md)。

**适配范围：**已有离线宿主试验使用 Windows DSH Desktop CLI 0.2.2-rc.5、嵌入 Node 24.21.0。工具返回与模型的最终回答需分别核验；不承诺其他系统、图形界面本地包安装、任意口语召回或完整历史检索。

## 查主题或精确撤回

想按关键词浏览，可以问「在这个工作区，帮我找找提到潮汐计划的记忆」，再要求展开含目标词的原话。见[主题浏览](docs/TOPIC-BROWSE.md)。这不是跨项目检索，也不能证明人物身份或当前偏好。

要删的和要留的请分开说。例如只删一条原文，可独立发送「删除原话：「我排练时带蓝色剧本。」」中的命令（外层引号不输入）；若只记得独特片段，可发「把包含「蓝色剧本」的那条记忆删除」。请以你自己的真实原句替换示例。只给主题、同时要求删甲留乙、候选不唯一或无法核对时，不应猜着删。取得 `deleted:true` 才算成功；其它结果先保留，必要时另发能确认的真实记忆 ID。对本句拒存、提及过去删过、现在要求删除，是不同操作；不要把先前的历史叙述当成新的同意。

**角色扮演提醒：**即使工具找对物品和台词，小模型也可能把角色的“我”错说成用户本人，或自然追问时根本不查。要求列出「用户/助手原文 + 谁在扮演谁」，以原句为准，缺证据就不推断。
